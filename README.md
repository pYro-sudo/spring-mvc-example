# Симуляция системы учета в детском саду

Данный проект направлен на разработку web-приложения по rest-у для учета за составом детского сада. Создание было мотивировано лабораторной работой.

## Технологический стек

*   **Backend:** Java 17, Spring Boot
*   **Базы данных:** PostgreSQL, Elasticsearch
*   **Кеш** Redis

## Архитектура и ключевые возможности

Пользователь входит в систему, вводя логин и пароль. У пользователя есть возможность регистрации. Когда тот смог войти в систему, ему предоставляется учет за воспитаетлями, родителями, детьми, кабинетами. Возможности ограничены лишь тем, есть ли у вас JWT & соответствующие права. Для быстрой обработки данных используется Redis. Для хранения важных данных пользователя(логин+пароль), используется PostgreSQL. Для остальных целей Elasticsearch.
